# 📊 Project Payment Tracking Dashboard

## 📌 Overview

The **Project Payment Tracking Dashboard** is an interactive Business Intelligence solution developed in **Power BI** to monitor project payments, revenue performance, and project status across multiple categories. The dashboard enables stakeholders to track payment progress, analyze revenue trends, identify rejected projects, and gain actionable insights through dynamic visualizations.

This project demonstrates skills in **Data Analysis, Data Modeling, Power BI, DAX, Power Query, and Business Intelligence Reporting**.

---

## 🎯 Project Objectives

* Monitor overall project payment performance.
* Track paid, pending, invoiced, and rejected projects.
* Analyze revenue trends over multiple years.
* Compare project performance across different project types.
* Provide business insights through interactive dashboards and KPIs.
